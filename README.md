# Skýrsla

## Inngangur
Hugmyndin að verkefninu kom þegar ég var að læra fyrir lokapróf. Þá notaði ég þá aðferð að niðurhlaða allt námsefnið og láta gervigreind greina áherslupunkta úr efninu og búa til lokapróf eða verkefni til að leysa fyrir prófin. Ég nefndi þessa hugmynd við félaga minn og hann sagði mér að Canvas byði upp á API sem væri hægt að nota til að gera svona lausn. Ég hugsaði fyrst um þetta sem „side project“, en svo kom í ljós að þetta væri fullkomið verkefni fyrir Vefforitun 2. Það sem kveikti hugmyndina mest var einfaldlega spurningin: af hverju er ekki til „niðurhala allt“ takki?

## Útfærsla
Verkefnið er unnið staðbundið og byggir á Canvas API-inu. Markmiðið var að búa til lausn þar sem hægt er að niðurhlaða allt námsefnið eða ákveðna hluti á einfaldari hátt. Skilyrðin voru uppfyllt með því að tengja verkefnið við Canvas API, sýna gögn í viðmóti og útfæra þá virkni sem þarf til að safna saman og hlaða niður efni. Verkefnið var þróað í áföngum þannig að fyrst var grunnurinn settur upp, síðan viðmótið og loks virkni tengd gagnavinnslu og niðurhali.

## Tækni
Í verkefninu var notað Next.js til að byggja framendann. Einnig var Canvas API notað til að sækja gögn úr Canvas. Verkefnið er keyrt staðbundið, þannig að ekki er um hefðbundna netþjónustu að ræða í notkun fyrir lokanotanda. Þessi tækni var valin vegna þess að hún hentar vel fyrir nútímalegt vefviðmót og samræmist vel verkefni sem tengist Canvas.

## Hvað gekk vel
Það gekk vel að tengja hugmyndina við raunverulegt vandamál sem ég hafði sjálfur upplifað. Einnig gekk vel að koma grunninum í gang og byggja verkefnið upp í skýrum skrefum. Það hjálpaði að halda fókus á einfalda og nytsamlega lausn.

## Hvað gekk illa
Það sem gekk helst illa var að finna út úr hvernig Canvas API virkar — það var erfitt að skilja hvað er hvað, sérstaklega vegna þess að það er ekki mikið skráð. Að auki var krefjandi að samræma hugmyndina, tæknina og framkvæmdina þannig að verkefnið yrði bæði nytsamlegt og einfalt. Þegar unnið er staðbundið getur líka verið meiri vinna að halda utan um uppsetningu og keyrslu verkefnisins.

## Hvað var áhugavert
Það var áhugavert að sjá hvernig ein einföld hugmynd, eins og „af hverju er ekki til niðurhala allt takki?“, getur orðið að fullgildu verkefni. Það var líka gagnlegt að tengja eigin námserfiðleika við forritunarverkefni. Verkefnið sýnir vel hvernig vefforritun getur leyst raunveruleg vandamál á hagnýtan hátt.
